🌦️ Weather App 🌍
A simple 🌐 Real-Time Weather App that displays current weather conditions for any city worldwide using the OpenWeatherMap API 🔥.

🌟 Features:
🌡️ Temperature Display
💧 Humidity Percentage
💨 Wind Speed
🌤️ Weather Status
🔍 City-Based Search

💪 Tech Stack:
💻 HTML + CSS
⚡ python
🔑 OpenWeatherMap API

🎯 How It Works:
Enter the City Name 🏙️
Click the Search Button 🔍
